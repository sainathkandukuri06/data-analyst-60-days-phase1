# Day 31 - Introduction to Power BI & Getting Started

## 1. What is Power BI?

Power BI is a Business Intelligence tool used to analyze data and create interactive reports and dashboards.

### Main Uses of Power BI

- Connect to different data sources.
- Clean and transform raw data.
- Create interactive charts and graphs.
- Build business dashboards.
- Analyze business performance.
- Generate meaningful insights for decision-making.

## 2. Components of Power BI

Power BI has three important components:

### 1. Power BI Desktop
- Used to connect and import data.
- Used to clean and transform data.
- Used to create reports and visualizations.
- Used to build data models.

### 2. Power BI Service
- Cloud-based platform.
- Used to publish reports.
- Used to share dashboards and reports.
- Helps organizations collaborate.

### 3. Power BI Mobile
- Used to access reports on smartphones.
- Helps users monitor business performance.
- Provides access to dashboards while traveling.

## 3. Power BI Desktop Interface

Power BI Desktop provides different views for working with data.

### A. Report View
- Used to create reports.
- Helps build charts, graphs, and tables.
- Used to design interactive dashboards.

### B. Data View
- Displays imported data in table format.
- Helps inspect rows and columns.
- Used to check data values and data types.

### C. Model View
- Displays relationships between tables.
- Helps connect multiple datasets.
- Important for creating accurate data models.

## 4. What is Get Data?

Get Data is a feature in Power BI used to connect different data sources.

### Common Data Sources

- Microsoft Excel
- CSV Files
- SQL Server
- Text Files
- Web Sources
- Other databases and cloud services

### Steps to Import Excel Data

1. Open Power BI Desktop.
2. Select the Home tab.
3. Click Get Data.
4. Select Excel Workbook.
5. Choose the required Excel file.
6. Select the worksheet.
7. Click Load.

The selected data will be imported into Power BI.

## 5. Excel and CSV Files

### Excel File (.xlsx)

Excel stores information in worksheets containing rows and columns.

Features:
- Supports multiple worksheets.
- Supports formulas and formatting.
- Can contain charts and tables.
- Useful for data analysis and reporting.

### CSV File (.csv)

CSV stands for Comma-Separated Values.

It stores information as plain text, with commas separating values.

Features:
- Simple text-based format.
- Easy to import and export.
- Commonly used for transferring datasets.
- Generally stores one table per file.

## 6. What is a Dataset?

A dataset is a collection of related information organized into rows and columns.

Example:

| Employee_ID | Name | Department | Salary |
|---|---|---|---:|
| 101 | Ravi | IT | 35000 |
| 102 | Sita | HR | 30000 |
| 103 | Arun | Finance | 40000 |

- Rows represent individual records.
- Columns represent attributes.
- Cells contain individual values.

Power BI uses imported data to create reports and perform analysis.

## 7. What is a Dashboard?

A dashboard is a visual summary of important business information.

### Common Dashboard Elements

- Total Revenue
- Total Orders
- Total Customers
- Monthly Sales
- Top-Selling Products
- Regional Sales Performance

### Benefits of Dashboards

- Easy understanding of business performance.
- Quick identification of trends.
- Better decision-making.
- Saves time in reporting.
- Provides meaningful business insights.

**Note:** Power BI reports can have multiple pages, while Power BI Service dashboards are generally single-page collections of pinned visuals.

## 8. Power BI Workflow

The basic Power BI workflow includes:

1. Get Data - Connect to different data sources.
2. Transform Data - Clean and prepare raw data.
3. Data Modeling - Create relationships between tables.
4. DAX Calculations - Create calculations and measures.
5. Data Visualization - Create charts, graphs, and reports.
6. Publish Reports - Share reports through Power BI Service.

| Concept | Purpose |

| Report View | Create visualizations |
